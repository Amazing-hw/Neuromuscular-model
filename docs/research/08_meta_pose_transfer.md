# 研究主线重构：验证多源 EMG 预训练对手部姿态估计的价值

2026-11-03。实现入口与操作步骤见 [POSE_TRANSFER.md](../../POSE_TRANSFER.md)。本文件替代旧方案中“五个下游任务同时铺开”的首阶段安排；旧研究笔记保留作为背景资料。

## 1. 要验证的命题

目标是利用 Meta 发布的 emg2pose、emg2qwerty，以及 GNI 的手势、书写、腕角任务，学习一个共享 EMG encoder，再在 emg2pose 上监督微调。其他任务标签不进入 SSL 或姿态微调。

三个命题需要拆开验证：

1. **表示预训练**：固定下游结构和预算，相比随机初始化，SSL 是否提高姿态精度、低标签效率和跨用户泛化？
2. **跨来源价值**：固定 SSL 总更新和输入呈现量，加入其他行为任务是否优于仅使用 pose 的 EMG？
3. **空间归纳偏置**：在前两项成立后，环形邻接是否进一步改善迁移及佩戴偏移鲁棒性？

单个 pose 任务的正结果足以支持“对姿态任务有价值的预训练 encoder”，还不足以独立支持通用 EMG 基础模型的广泛能力，更不能单靠模块组合保证 CCF-A 投稿创新。

## 2. 为什么调整原实现

原 encoder 的时间 attention 没有显式时间位置，不能完整区分时间片的排列；通道平均读取会强化循环移位不变性，但绝对肌群/电极身份恰可能影响手指姿态。原先 latent teacher 的常量解是目标函数允许的解，不能仅以 loss 下降论证学到可迁移的生理结构。原逐 token 线性姿态头与插值对长时状态估计也偏弱。

这些是结构和实验解释上的风险，不代表旧代码实际训练必然坍塌。新实现保留旧路径以便回溯，以较简单、可解释的监督信号和 encoder/decoder 分工建立可靠实验基础。

## 3. 输入、归一化与时间质量

所有输入为单腕 `X∈R^(T×16)`，2 kHz；不把左右腕拼成 32 通道。不同频率直接报错，需要事先明确重采样方案。H5 转换保持原始信号，新路径在加载时按来源固定 RMS 缩放，并在 patch 投影前使用 `sign(x)*log(1+abs(x))` 压缩大幅值。固定来源标度只从 train 统计拟合，保持同一来源内部的通道间比例与窗口间幅值变化。

此选择并不解决所有域差异：来源标度可能消除一部分有用增益信息，来源差异也可能成为模型捷径。应比较固定全局标度、来源标度，以及来源/腕侧分组误差。不要未经验证使用逐窗口独立归一化，它会抹掉强度信息，若依赖整窗统计还会破坏严格的因果解释。

时间戳跳变形成独立连续区间，窗口不跨间隙。默认 train 窗 1 秒、步长 0.5 秒；评估为 5 秒非重叠窗口。短片段与尾部丢弃数量需随结果报告。采集时钟与名义采样率仍有残余抖动，新路径没有把它们当作已完成物理校准。

## 4. Encoder：保留身份，显式建模时间

流程为：

```text
16通道原始 EMG
  → train-only 来源标度
  → 非重叠 40-sample / 20-ms patch
  → 共享单通道投影 + 可学习电极身份
  → [可选] 环形相邻通道深度卷积残差
  → 按通道顺序拼接并投影
  → 正弦时间位置 + 因果 Transformer
  → 每20ms一个共享运动表征
```

默认 ring_mixing=false，先验证预训练本身。通道不是无序集合，也不硬编码全腕旋转不变性。可选环形局部混合使用 wrap-around 邻接，但最终读取仍保留电极身份。

用户提到的“时序与通道十字关系”有合理启发：把时间依赖和空间依赖分开处理，通常比对所有时空 token 做全连接更可控。然而环形拓扑、左右腕映射和肌肉解剖不是等价概念。这里先用共享 patch + 有序读取建立对照，不将“十字注意力 + 环形结构”当作已证明的创新。后续可将空间混合升级为带环距离偏置的 attention，并与同参数普通空间混合比较。

## 5. SSL：恢复固定信号统计

对每个 patch/channel，计算原缩放信号的 rFFT power：`|rFFT(x)|²/P`，平均池化为 K=8 个频谱 bin，再加一个 RMS；对它们取 log1p，得到固定 K+1 维目标。此处没有 Hann 窗或医学定义频带，不应写成精确生理频带分解。

遮挡结合连续时间块、随机通道位置与连续环形电极弧；首 token 保持可见。mask 位于投影后、所有跨通道和跨时间混合前，遮挡内容不能通过这些路径泄露。目标仅用于被遮挡位置的 SmoothL1 回归。因果 Transformer 只能利用历史 patch 和当前未遮挡通道。

固定、随输入变化的目标排除了“teacher 与 student 同时变常量即可得到零误差”的自由度，但仍可能产生只预测平均能量的弱表征。应监测重建误差、latent 标准差，并将下游表现作为最终判据；不能把非零方差当作充分的防坍塌证明。

时间块遮挡要求利用动作动态，通道弧遮挡要求利用腕周共激活结构。后续消融顺序：时间遮挡 / 通道遮挡 / 二者结合；log-spectrum vs waveform vs 联合目标；ring on/off；来源温度 alpha=0/.5/1。先做单因素变化，不同时堆加所有模块。

## 6. 姿态微调与因果评估

encoder 权重迁移后，重新初始化 GRU 与 20 维角度头，全参数微调。GRU 维护窗口内历史状态；不喂入真实初始角度，因此研究对象是 regression。没有实现 tracking 作为默认任务，也没有直接复制官方 vemg2pose 的速度积分 decoder。

一个 patch 的输出只能在其末样本到达后使用。预测按可用时间零阶保持到 2 kHz 标签网格；不能线性插值到尚未到达的下一 token。默认前 39 个样本未产生预测而排除，剩余角度与 IK mask 对齐。每个评估窗口重置状态，这与整段连续部署不同，需报告该限制。

以所有有效角度元素的绝对误差总和/数量计算 MAE，平方误差总和/数量开方计算 RMSE，再从 rad 转 deg。DDP 补齐样本计零权重，各 rank 先汇总充分统计量，避免平均 batch RMSE 的错误。并列报告平均帧与平均用户误差、官方 generalization 和 stage 子组。

这是严谨的内部对照协议，而非现成官方评测复现。官方实现及论文还提供 FK/landmark 指标，并区分 regression / tracking。若后续对外声称优于官方 baseline，需要用固定版本官方代码完成同协议复现或接入新 encoder。[官方仓库](https://github.com/facebookresearch/emg2pose)、[emg2pose 论文](https://arxiv.org/html/2412.02725v1)。

## 7. 数据泄漏和实验解释

五类数据共同用于预训练不等于“所有文件都能训练”。只选择 train，不用姿态 val/test 的无标签信号；归一化也遵守这一原则。文件哈希跨 split 重复直接报错。跨发布受试者身份无可靠映射时，不能声称完成了严格跨语料 identity 去重。

本地官方 pose 清单存在 540 个相反腕侧跨 train/test 的记录配对。默认排除训练侧，从而减少同步行为相关性；官方 test 原样保留。这个训练池与完整官方 train 有差别，因此 A–E 共同遵守此政策，官方基线也应在相同池重跑，或另设完整官方训练池的实验。此过滤不能消除同一用户的所有相关性，也不应破坏官方 held-out-stage 本来允许的用户重合。

低标签预算按原始 session 分组取嵌套子集，并记录真实帧、session、subject 数。不能随机抽高度重叠窗口，再把百分比当成独立标注量。

## 8. 实验矩阵与阶段决策

|阶段|实验|继续的判断依据|
|---|---|---|
|软件验证|合成及真实小样本全链路、因果性、mask、权重迁移、指标测试|流程正确；不据此判断精度|
|最低可行科学验证|A/B/D，100% 标签，3 seeds，固定所有预算|B−A 区分 SSL；D−B 区分外部来源|
|排除替代解释|C、E；10%/1%；同参数/同微调搜索预算|正迁移不只来自训练更久或标签抽样偶然性|
|机制验证|来源逐个加入/去除、ring消融、目标/遮挡消融|哪类信号信息在何种泛化场景产生作用|
|投稿级结果|官方同协议强基线、FK、更多用户统计、算力/规模曲线|可重复效果、机制解释和充分对照形成论文贡献|

评估主要看 paired seed 差值，同时以用户为单位分析统计不确定性。窗口高度相关，不以窗口数作为独立样本数人为缩小置信区间。超参数选择只使用 val，test 在策略冻结后评估；每个方法的搜索次数与预算也应匹配。

E 的 60k 监督更新只匹配 D 的 40k SSL + 20k 微调总步数，并非自动 FLOPs 匹配。报告实际 GPU 小时、全局 batch、输入 token 数与参数量，再补时间/计算量匹配对照。

## 9. 创新空间与否定条件

目前代码是一套更可信的迁移实验基线，**没有把常见组件的组合宣称为新算法**。可探索的研究贡献是“固定腕周拓扑下，跨行为数据的哪类局部共激活与时间动态构成可迁移表征”，再由严谨消融决定是否需要新的结构或目标。

如果 D 不优于 B，应承认额外数据在当前设置下没有收益，进一步定位负迁移来源；若 B/D 不优于 A/E，应重新评估信号目标、下游 decoder、训练尺度以及预训练的必要性。保留这些可证伪条件，比提前固定复杂模型名称更有价值。

作为首阶段结论，只讨论“多源 EMG 预训练是否改善 emg2pose”；后续若要主张广泛基础模型能力，再增加独立任务和迁移设备的验证。GNI 官方数据与任务说明可见 [generic-neuromotor-interface](https://github.com/facebookresearch/generic-neuromotor-interface)。
