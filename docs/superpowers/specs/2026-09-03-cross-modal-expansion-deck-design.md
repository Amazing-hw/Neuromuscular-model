# 生理时序基础模型 PPT 跨模态扩充设计

## 1. 目标与边界

在已交付的 100 页、17 篇论文深读版基础上制作一个新副本，保留原文件不变。新版本加入语音自监督学习与非 EEG 生理基础模型，用这些领域已验证的 tokenizer、掩蔽目标、教师表示、离散码本和缺失模态训练机制，补强面向 1 kHz 前臂/腕部 sEMG 的预训练方案。

研究任务仍限定为离散手势、连续手指/腕部运动和交互序列；身份信息只作为域捷径审计变量，不恢复疲劳或身份识别主线。

8. ECG-FM：ECG 特异增强、对比学习和连续信号掩蔽的混合预训练。

## 5. 跨模态方法结论

最终推荐的 sEMG 主干不直接复制语音离散语言模型，而采用分阶段组合：

- 主路径：多尺度连续 tokenizer 与 data2vec 式 masked teacher latent prediction，优先保留连续运动信息。
- 鲁棒路径：借鉴 WavLM，将腕带旋转、轴向位移、通道掉线、增益变化、饱和和工频污染作为结构化 corruption。
- 多模态路径：借鉴 SleepFM，以 sEMG、IMU 和手部运动学做 leave-one-modality-out 对齐，部署时保证 sEMG-only。
- 离散可选路径：先用 BEST-RQ 检验随机离散目标，再与 wav2vec 2.0、BEATs、HeartLang 或 ECG2TOK 式可学习语义 tokenizer 比较。

目标模型必须同时报告离散手势和连续轨迹性能；码本路线额外报告 perplexity、死码率、量化误差、跨日 token 稳定性以及 token 与设备/受试者身份的互信息。
